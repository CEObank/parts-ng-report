# Operation Excellence - Parts NG Report System

เว็บแอปสำหรับบันทึกและสรุปภาพรวมชิ้นงานเสีย (NG/Rework/Other) ระหว่างกระบวนการผลิต ของ Baojie Electric Motor (Thailand)

## สถาปัตยกรรม

ระบบนี้เป็น **Cloudflare Pages + Pages Functions + D1** (ฐานข้อมูลกลางแบบ SQL บนคลาวด์ของ Cloudflare) ทำให้ข้อมูลทั้งหมด (บัญชีผู้ใช้, สิทธิ์การลงทะเบียน, รายงานชิ้นงานเสีย) ถูกเก็บไว้ที่เดียวกันบนเซิร์ฟเวอร์ ไม่ใช่แยกเก็บในแต่ละเครื่องแบบเดิม ทุกเครื่อง (คอมพิวเตอร์, มือถือ, แท็บเล็ต) ที่เปิด URL เดียวกันจะเห็นข้อมูลตรงกันแบบเรียลไทม์

โครงสร้างไฟล์:
- `index.html` — หน้าเว็บทั้งหมด (ฟอร์มบันทึกข้อมูล, Dashboard, จัดการผู้ใช้, สิทธิ์การลงทะเบียน) รองรับ 3 ภาษา (ไทย/EN/中文)
- `functions/api/*` — Backend API (Cloudflare Pages Functions) จัดการ login, register, รายงาน, ผู้ใช้, สิทธิ์การลงทะเบียน
- `schema.sql` — โครงสร้างฐานข้อมูล D1
- `wrangler.toml` — ไฟล์ตั้งค่าโปรเจกต์ Cloudflare

**สำคัญ**: ไฟล์นี้ **ใช้งานได้เฉพาะเมื่อ deploy ขึ้น Cloudflare แล้วเท่านั้น** ไม่สามารถดับเบิลคลิกเปิดตรงๆ แบบไฟล์เดี่ยวได้อีกต่อไป เพราะต้องพึ่งฐานข้อมูลกลางบนเซิร์ฟเวอร์

## วิธี Deploy (ทำครั้งเดียว)

### สิ่งที่ต้องมี
- บัญชี Cloudflare (ฟรี) — สมัครที่ cloudflare.com
- ติดตั้ง Node.js บนคอมพิวเตอร์ (ถ้ายังไม่มี ดาวน์โหลดที่ nodejs.org)

### ขั้นตอน

เปิด Terminal / Command Prompt ในโฟลเดอร์นี้ แล้วรันตามลำดับ:

```bash
# 1) ติดตั้งเครื่องมือ wrangler (ตัวจัดการของ Cloudflare)
npm install

# 2) ล็อกอินเข้าบัญชี Cloudflare (จะเปิดเบราว์เซอร์ให้กดยืนยัน)
npx wrangler login

# 3) สร้างฐานข้อมูล D1 (ทำครั้งเดียว)
npx wrangler d1 create parts_ng_report_db
```

คำสั่งข้อ 3 จะแสดงผลลัพธ์ที่มี `database_id` ให้คัดลอกค่านั้นมาใส่แทนที่ `REPLACE_WITH_YOUR_DATABASE_ID` ในไฟล์ `wrangler.toml`

```bash
# 4) สร้างตารางในฐานข้อมูลจริงบน Cloudflare
npx wrangler d1 execute parts_ng_report_db --remote --file=schema.sql

# 5) Deploy ทั้งเว็บไซต์และ API
npx wrangler pages deploy .
```

ครั้งแรกที่ deploy ระบบจะถามชื่อโปรเจกต์ (เช่น `parts-ng-report`) หลังจากนั้นจะได้ URL เช่น `https://parts-ng-report.pages.dev`

### เชื่อมฐานข้อมูลเข้ากับเว็บไซต์ (ทำครั้งเดียว ผ่านหน้าเว็บ Cloudflare)

หลัง deploy ครั้งแรก ต้องไปผูก D1 เข้ากับ Pages project ผ่าน dashboard อีกหนึ่งครั้ง:
1. เข้า Cloudflare dashboard → Workers & Pages → เลือกโปรเจกต์ที่ deploy ไป
2. ไปที่ Settings → Functions → D1 database bindings
3. เพิ่ม binding: Variable name = `DB`, Database = `parts_ng_report_db`
4. กด Save แล้ว deploy ซ้ำอีกครั้ง (`npx wrangler pages deploy .`) เพื่อให้การผูกมีผล

จากนั้นเข้า URL ที่ได้ ระบบจะพร้อมใช้งานจริง คนแรกที่สมัครจะได้เป็น Admin อัตโนมัติ

### อัปเดตโค้ดในอนาคต

ถ้ามีการแก้ไขไฟล์ (เช่น ผมส่งไฟล์ใหม่มาให้) ให้รันแค่:
```bash
npx wrangler pages deploy .
```
ไม่ต้องสร้างฐานข้อมูลใหม่หรือทำขั้นตอนผูก D1 ซ้ำ (ข้อมูลเดิมยังอยู่ครบ)

## ฟีเจอร์หลัก

- ฟอร์มบันทึกชิ้นงานเสีย พร้อมถ่ายรูปจากกล้อง (เว็บแคม/มือถือ)
- ผู้รายงานล็อกชื่อตามบัญชีที่ login อัตโนมัติ
- พนักงานลงข้อมูลได้เฉพาะ Team ที่ Admin authorize ไว้เท่านั้น (บังคับทั้งฝั่งหน้าเว็บและฝั่งเซิร์ฟเวอร์)
- Dashboard สรุปรายวันแยกตามไลน์ (Assembly A/B/C, Stator, Varnish Coating) พร้อมกราฟ
- Export CSV, Export Excel (ฝังรูปภาพจริงในไฟล์), Export/Import JSON สำรองข้อมูล
- เวลาที่บันทึกอ้างอิงเวลาประเทศไทย (Asia/Bangkok) เสมอ ไม่ว่าอุปกรณ์จะตั้งโซนเวลาใด
- Admin จัดการผู้ใช้งานและสิทธิ์การลงทะเบียนได้ในหน้าเว็บ
- รองรับ 3 ภาษา: ไทย / English / 中文
- ใช้งานได้ดีทั้งบนคอมพิวเตอร์และมือถือ

## หมายเหตุด้านความปลอดภัย

- รหัสผ่านเข้ารหัสด้วย PBKDF2 (SHA-256, 100,000 iterations) พร้อม salt เฉพาะแต่ละบัญชี ไม่เก็บรหัสผ่านตรงๆ
- การเข้าสู่ระบบใช้ session token ที่หมดอายุใน 30 วัน
- Team ของพนักงานถูกกำหนดจากการ authorize ของ Admin เท่านั้น พนักงานไม่สามารถเลือก Team เองตอนสมัครได้
- ระบบนี้เหมาะกับการใช้งานภายในทีม/บริษัท ไม่ได้ออกแบบมาสำหรับงานที่ต้องการมาตรฐานความปลอดภัยระดับสูงสุด (เช่น ข้อมูลทางการเงินหรือข้อมูลส่วนบุคคลที่อ่อนไหว)
